## Overview dashboard

- Cards flow through a responsive 12-column grid, fill the window at any width and fit their content. Drag a card to move it, drag a side border to change its width, or use **Auto arrange** to group and size every card evenly.
- New optional **Loaded models** card lists every running session; select one to show it in the other cards.
- Metrics show warning and critical states with adjustable thresholds, dim when their source stops answering, and stay visible with a reason when unreported.
- Charts show their time span, min/max/latest readouts and a stable scale from zero. Cards add speculative speed-up and prompt-cache hit rate, and copy their readings with **Copy readings** or Ctrl+C.

## Launch profiles and runtimes

- K/V cache type, reasoning format and RoPE scaling list the values the selected runtime supports, such as TurboQuant `turbo2`/`turbo3`/`turbo4` cache types.
- Support the `draft-dflash2` and `draft-lilicorr` speculative types.
- Unsaved launch-setting edits survive list refreshes and ask before you leave; profiles from earlier versions no longer ask to be saved when unchanged.
- Startup profiles load in the background with visible progress, so the window and gateway are usable immediately.
- Official CUDA WSL packages now include their matching CUDA runtime libraries.

## Gateway and automation

- The gateway rejects requests from non-local web pages, waits for streaming responses before Single active swaps or idle unload, and stops llama-server work when a client disconnects.
- Audio transcription and image edit requests now route to the right model.
- `llwmctl` reports blocked operations as failures, protects the agent's own session more reliably, and no longer requires `--allow-self-stop` for agents whose model is not served by this Manager.

## Security and reliability

- Custom launch parameters that download remote models, expose files or tunnels, or run tools/MCP servers are rejected at launch, in benchmarks and on import.
- A failed app update restores and restarts the previous version; updates and runtime packages verify checksums by exact file name and report unverified packages honestly.
- The Manager refuses a database created by a newer version, keeps partial Hugging Face downloads after network errors, and no longer freezes or misreports stops for WSL sessions.
- Only helper files the Manager installed are replaced beside its executable.

## Interface

- Every interface string, help article and tooltip is translated in all 21 languages.
- The System theme follows Windows light/dark changes; UI and text scale apply on release, with a reset button, and controls grow with large text.
- Table column edges keep resizing after a neighbouring column reaches its minimum; editable drop-downs show their text box again.
- Refused actions show a visible notice, and settings editors have accessible names.

## Upgrade notes

- A saved profile whose **Custom params** use a newly blocked option reports it by name and must be edited before it loads.
- Reinstall or update an existing official CUDA WSL runtime to add its CUDA libraries.
- Dashboard layouts keep their previous reading order after migrating to the new grid.
- The bundled .NET runtime is updated to the 10.0.15 security release.
- This release is unsigned. From v2.7 or later, update through the app with SHA-256 verification; from v2.5 or v2.6, install manually once and keep your data folder.
