# Profile import and export (#79)

- Export one profile or all profiles for one model as readable versioned JSONC.
- Copy/paste profiles and copy a profile to another registered model through the
  same preview, with Keep both (default), Replace and Skip name conflict choices.
- Review local runtime, companion, GPU and port mappings; edit settings or browse
  companion files before saving. Missing companions block import. Replacements
  preserve IDs and references; new profiles get fresh IDs and available ports.
- Persist profile notes and per-setting annotations through ordinary settings
  saves and exports. JSON comments are accepted for hand editing.
- Import selected profiles atomically, rechecking catalog and session state.
  Transfers never load or restart models and do not include credentials, binaries
  or app preferences.
- Add supported `llwmctl profiles export|import` commands; import previews by
  default and requires `--apply` to save.

- Support Ctrl+C on saved profiles and Ctrl+V into another selected model, with
  normal text editing shortcuts preserved and shortcut hints in context menus.
- Paste into the destination's saved profiles list even when it is empty or
  keyboard focus has moved outside the tables; release shortcuts on navigation.
- Keep import actions visible when resizing the preview at increased UI scale;
  long warning lists remain scrollable.
