- Custom launch parameters that download remote models (`-hf`, `--model-url`),
  serve local folders (`--path`), send data to remote hosts (`--rpc`), or write
  files (`--log-file`, `--slot-save-path`) are now rejected at launch, in
  benchmarks, and on profile import.
- Upgrade action: a saved profile that already uses one of these options fails
  to load with a message naming it. Remove the option from **Custom params** and
  save the profile.
