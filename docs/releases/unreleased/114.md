- Custom launch parameters that download remote models (`-hf`, `--model-url`),
  serve local folders (`--path`), or send data to remote hosts (`--rpc`) are now
  rejected at launch, in benchmarks, and on profile import.
- Imported profile bundles can no longer set where files are written
  (`--slot-save-path`, `--log-file`); these still work when set locally.
- Upgrade action: a saved profile that already uses a rejected option fails to
  load with a message naming it. Remove the option from **Custom params** and
  save the profile.
