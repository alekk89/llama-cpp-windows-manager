- `llwmctl` now checks whether the calling agent's model is served by this Manager before refusing a stop. An agent using a cloud model, another host, or an unused local port can unload or restart local models without `--allow-self-stop`.
- `llwmctl self` reports `servedByManager` and recognises the gateway; endpoint hints now also require the host to be this computer. Under Claude Code, the agent's own `ANTHROPIC_BASE_URL` is used instead of a global `OPENAI_BASE_URL` set for other tools.
