- Copy the exact model ID from gateway and direct endpoint reports, with clearer labels and copy buttons.
- Saved profile aliases now appear in gateway discovery, with numbered names for duplicates.
- Direct endpoints use short model names by default, with an optional suffix for client routing.
- Turn off gateway auto-loading to serve only profiles you have already loaded.
- Choose whether another profile of the same model asks, loads alongside, or replaces existing profiles. Cancelling keeps current sessions running.
- Set a default runtime for new profiles without changing existing profiles.
- Profile Host IP now consistently follows LAN settings, including inherited defaults and explicit loopback addresses.
- Benchmark reports and exports show sampled peak dedicated and shared GPU memory for each device.
- Vulkan profiles can set an allocation block size for loading, fitting, and benchmarking.
- Display and text-scale changes no longer interrupt requests through an unchanged gateway.
- Fixed gateway startup after granting Windows permission for a new port.
- Improved table resizing, endpoint readability, and layout restoration during rapid navigation.
- Sidebar navigation now scrolls at larger scales so lower pages stay reachable.
- Windows and WSL refresh buttons now clearly say Refresh environment.
- Updates wait for the replacement helper before closing and preserve recovery files if rollback fails.
- Read-only database and migration errors preserve existing state instead of resetting it.
- Session logs no longer collide, and download preparation errors no longer leave jobs stuck in the queue.
- Benchmarking handles malformed results and background process cleanup more reliably.
- Startup settings no longer overwrite another installation's registration.

- Portable download is now a single EXE; the ZIP has been removed.
- Unsigned updates now verify SHA-256 checksums before installation.
