- v2.6 remembers your workspace. Resized table columns, reordered columns, splitter positions, page proportions, and the main window size and position are restored when you return or restart the Manager.
- Search and persistent favourites now work consistently for models, launch profiles, and runtimes, with favourite-first ordering across selectors, lists, Overview, and the tray.
- Choose several saved launch profiles to load with the Manager, using the searchable startup setting or the direct action on Saved Launch Profiles.
- Multiple profiles of the same model can run together on separate ports and GPUs, with safer group loading and session-specific selection and recovery.
- ROCm is now a first-class runtime for Windows and WSL. Runtime downloads also select the newest compatible llama.cpp build, and launch profiles can save a host IP.
- UI scale and Text scale work independently, with more compact controls and freely resizable table columns throughout Overview, Models, Runtimes, Benchmarks, and Settings.
- Benchmarking now includes saved-profile serving, VRAM and memory fit checks, profile fitting, clearer comparisons and exports, and guided recovery after an out-of-memory launch.
- Boring but important improvements to runtime readiness, session tracking, accessibility, refresh work, and regression coverage.

These builds are still unsigned, so Windows may show a warning. Verify downloads with the matching SHA-256 file included with each release artifact.
